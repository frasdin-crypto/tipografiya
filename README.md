## Как запустить

Нужны **PowerShell** и доступ в интернет (скрипт сам скачает `sqlite3`, если его нет в PATH).

```powershell
cd C:\Users\рома\tipografiya
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

После сборки появится файл `printshop.db`. Запросы:

```powershell
.\tools\sqlite3.exe printshop.db ".read queries.sql"
```

Если `sqlite3` уже установлен:

```powershell
sqlite3 printshop.db ".read schema.sql"
sqlite3 printshop.db ".read import.sql"
sqlite3 printshop.db ".read queries.sql"
```

## Предметная область

Типография принимает заказы от организаций: визитки, листовки, буклеты, плакаты, каталоги, наклейки, бланки, баннеры. У заказа есть клиент, менеджер, сроки и позиции. Для изделий заданы тип бумаги и нормы расхода краски и расходников.

## Сущности (8)

1. `clients` — заказчики  
2. `employees` — сотрудники  
3. `paper_types` — типы бумаги  
4. `products` — виды продукции  
5. `materials` — материалы на складе  
6. `product_materials` — нормы расхода (связь M:N)  
7. `orders` — заказы  
8. `order_items` — позиции заказа  

Подробности, ER-диаграмма и нормализация — в [REPORT.md](REPORT.md).
